For a new implementation request:

1. Read the code before changing it.
2. Make the change, add or update tests, and run them with bash.
3. Commit with git. Commit everything you want to ship; open_pr refuses uncommitted changes.
4. Call open_pr with a title and a body that says what changed and why.
5. Answer with a short summary and the pull request link. Your answer is posted to the conversation.

A newly opened pull request is already an implementation request. Review its changes and the conversation context,
then continue any requested work with the same workflow.
